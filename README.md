# Homeasistant-to-wordpress
Попытка навайбкодить вывод датчиков на сайт.



Через HACS (Custom Repository)
​Если вы храните свои компоненты на GitHub:
​Загрузите файлы компонента в свой репозиторий на GitHub.
​В Home Assistant откройте HACS → Интеграции.
​В правом верхнем углу нажмите три точки → Пользовательские репозитории (Custom repositories).
​Укажите ссылку на свой репозиторий, выберите категорию Интеграция (Integration) и нажмите Добавить.
​Найдите интеграцию в поиске HACS, нажмите Загрузить и перезапустите Home Assistant.
​Визуальная настройка в интерфейсе
​Перейдите в Параметры → Устройства и службы → Добавить интеграцию.
​В поиске введите WordPress Sensor Publisher.
​Заполните визуальную форму:
​REST API URL: вставьте адрес из настроек плагина WordPress (например, [https://your-site.com/wp-json/ha-publisher/v1/update](https://your-site.com/wp-json/ha-publisher/v1/update)).
​Секретный токен: скопируйте ключ X-HA-Token из админки сайта.
​Интервал отправки: задайте частоту в минутах (по умолчанию 5).
​Список датчиков: выберите любые нужные датчики из выпадающего списка.
​Нажмите Отправить. Интеграция проверит связь с сайтом и сразу отправит первую партию данных.
​Чтобы в будущем изменить список датчиков или частоту синхронизации, просто нажмите кнопку «Настроить» на карточке интеграции в меню Устройства и службы.
